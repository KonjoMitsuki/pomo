# 2026年5月1日 `!help` 重複表示・再投稿不可の修正レポート

## 1. 概要

本セッションでは、Pomodoro Bot の `!help` コマンドに関する以下2つの問題を修正しました。

1. `!help` 実行時にヘルプが2枚出る（重複表示）
2. 重複対策後に、1回表示すると新しいヘルプが出なくなる（再投稿不可に見える）

最終的に、`!help` 実行ごとに最新ヘルプを1件だけ表示し、かつ毎回新しいメッセージとして出る挙動に統一しました。

---

## 2. 背景と事象

ユーザー報告は次の流れでした。

1. 最初の報告: `!help` を実行すると同じヘルプが2回出る
2. 初回修正後の報告: 一度 `!help` を出すと、新しいヘルプが出せなくなった
3. 最終調整後: 「治りました」と確認

---

## 3. 原因

### 3.1 重複表示の原因

`!help` の実行時に同等内容の投稿が重なって残る状態があり、チャンネル上でヘルプが複数見える状態になっていました。

### 3.2 再投稿不可に見えた原因

重複対策の初期案で「既存ヘルプを編集（edit）」する方式を採用したため、
メッセージ自体は更新されても、チャンネル下部に新規メッセージが追加されず、
ユーザー視点では「新しいヘルプが出ていない」ように見えていました。

---

## 4. 実施した修正

対象ファイル: `src/cog.py`
対象箇所: `help_command`

### 4.1 方針

- 既存ヘルプの編集は廃止
- 同タイトルの既存ヘルプを先に削除
- 最後に必ず `ctx.send(embed=embed)` で新規投稿

### 4.2 実装要点

- `ctx.channel.history(limit=100)` で Bot が投稿した同タイトル embed を収集
- 収集した既存 help メッセージを順次 `delete()`
- 削除成否に関わらず最後に新規ヘルプを送信

この仕様により、

1. ヘルプは原則1件に整理される
2. `!help` を実行するたびに新しいメッセージとして可視化される

を同時に満たします。

## 7. 学び / 再発防止メモ

- Discord ボットで「重複抑止」を行う際、`edit` は履歴上の新規投稿にならないため UX とズレることがある
- 「毎回反応が見えること」が要求されるコマンドは、`delete + send` を優先すると期待との齟齬が少ない
- 例外時は処理継続可能な箇所（削除処理など）を fail-soft にして、最終返信（send）を優先する
